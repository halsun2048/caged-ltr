# 面向长尾搜索广告的完整复现与新实验清单

> 研究主题：面向长尾搜索广告的置信度感知语义—协同增强与多目标排序蒸馏  
> 技术链路：LLM 离线语义增强 → 语义—协同融合 → LLM 排序教师 → 轻量学生  
> 原则：先完成最小可信复现，再开展核心新实验；不追逐五篇论文全部原始小数点。  
> 标记：`[复现]`、`[新实验]`、`[可选]`、`[验收]`、`[停止]`。

## 0. 总体决策

- [ ] 将 20%—30% 的资源投入关键趋势复现。
- [ ] 将 70%—80% 的资源投入置信度感知新实验。
- [ ] 本地只训练轻量学生、小型序列模型和小规模对齐模型。
- [ ] PRP、FIRST、FLAN-T5 等教师使用云端、公开 checkpoint 或预计算标签。
- [ ] 不把“无人工相关性标签”写成“无需训练”。
- [ ] 不把 PRP 的 prompt A/B 交换写成曝光或展示位置去偏。
- [ ] 不把 FIRST 首 token logits 未经校准地解释为正确率。
- [ ] 没有可靠 propensity 时，不声称因果去偏或无偏 CTR。

核心闭环：

~~~text
训练时点前 Query/Ad 文本 → 离线语义 embedding
                              ↓
ID/CTR/协同表示 → 频次与不确定性感知门控 → 轻量学生
                              ↑
FIRST 风格 Listwise 教师 → 低 margin 候选 → 双向 PRP 复核
                              ↓
              置信度校准的 Pairwise + Listwise 蒸馏
~~~

## 5. 新实验：CAGED-LTR

全称：Confidence-Aware Gated Enhancement and Dual-granularity LTR Distillation。

### 5.1 研究问题

如何按语义、行为和教师偏好的样本依赖可靠性增强长尾 Query/Ad，并将带噪 Pairwise/Listwise 偏好蒸馏到低延迟广告排序模型？

### 5.2 核心创新

1. 频次与不确定性感知语义—协同门控。
2. Listwise 初判、低置信 Pairwise 复核的路由式双粒度蒸馏。
3. 小规模人审/qrels 上的教师置信度校准。

偏差校正仅在 propensity 可靠时作为独立扩展。

### 5.3 可检验假设

- H1：Tail 的最优语义权重高于 Head，行为权重随有效曝光量增加。
- H2：置信度加权优于等权硬标签，尤其在 Tail/OOD Query。
- H3：只对低 margin pair 调用 PRP，可显著降低教师成本并保持质量。
- H4：Pairwise 局部约束与 Listwise Top-K 结构具有互补性。
- H5：排序提升不必然改善 pCTR 校准。

## 6. 新模型与公式

### 6.1 语义—协同门控

\[
\tilde{\mathbf e}^{sem}=\operatorname{LN}(W_s\mathbf e^{sem}),
\qquad
\tilde{\mathbf e}^{collab}=\operatorname{LN}(W_c\mathbf e^{collab}).
\]

\[
g_x=
\sigma\left(
\operatorname{MLP}
[\log(1+n_x),age_x,textQuality_x,
semUncertainty_x,behUncertainty_x]
\right),
\]

\[
\mathbf h_x=
g_x\tilde{\mathbf e}_x^{collab}
+(1-g_x)\tilde{\mathbf e}_x^{sem}.
\]

- [ ] 两路先归一化，避免尺度主导 gate。
- [ ] 检查 gate 是否塌缩。
- [ ] 报告 gate 与曝光量、文本质量、误差的关系。
- [ ] 对照固定 0、1、0.5、频次启发式和随机 gate。

### 6.2 Listwise 教师

\[
P_T^{list}(i\mid q,C)
=
\frac{\exp(z_i^T/\tau)}
{\sum_{j\in C}\exp(z_j^T/\tau)}.
\]

- [ ] 温度在校准集选择。
- [ ] identifier 和 permutation 扰动审计。
- [ ] \(z_i^T\) 校准前只作为 slate-relative score。

### 6.3 Pairwise 路由

调用 PRP 的条件：

- Top-K 决策边界；
- Listwise margin 低；
- Listwise 与行为教师冲突；
- Tail 且文本完整；
- permutation 不稳定。

\[
c_{ij}^{pair}
=\operatorname{Calibrator}
(swapAgree,margin,promptStability,
behaviorAgreement,textQuality).
\]

### 6.4 联合损失

\[
\mathcal L=
\mathcal L_{sup}
+\lambda_g\mathcal L_{gate}
+\lambda_p\mathcal L_{pairKD}
+\lambda_l\mathcal L_{listKD}
+\lambda_c\mathcal L_{cal}.
\]

\[
\mathcal L_{pairKD}
=
\sum_{(i,j)\in\mathcal H}
c_{ij}^{pair}
\log(1+\exp[-y_{ij}^T(s_i^S-s_j^S)]).
\]

\[
\mathcal L_{listKD}
=
c_C^{list}\tau^2
\operatorname{KL}(P_T^\tau\parallel P_S^\tau).
\]

\[
\mathcal L_{cal}
=\frac1N\sum_i(\hat p_i-y_i)^2.
\]

有可靠 propensity 时：

\[
\mathcal L_{sup}^{IPS}
=\frac1N\sum_{i:o_i=1}
\frac{\ell(y_i,\hat p_i)}
{\max(\pi_i,\epsilon)}.
\]

## 13. 最终 Go/No-Go

作为论文主方案必须满足：

- [ ] 门控在至少两个数据集或一个真实广告日志上稳定改善 Tail。
- [ ] Head 下降在预设容忍范围内。
- [ ] Confidence weighting 优于等权和随机 confidence。
- [ ] Pair+List 优于至少一个单路教师。
- [ ] Routing 降低至少 50% Pairwise 调用并保留大部分增益。
- [ ] 排序提升不伴随显著校准恶化。
- [ ] 轻量学生满足 P99/QPS。
- [ ] 核心结论在 3—5 seeds 下稳定。
- [ ] 无未来信息、未验证商业属性或测试集调参。

降级策略：

- Gate 无增益：改为“置信度路由蒸馏”单核心。
- Pair/List 不互补：保留更强一路，研究置信度与成本。
- 无可靠 propensity：删除因果去偏主张。
- 多目标不稳定：先做 relevance + CTR。
- 教师成本过高：只保留高价值困难 pair。
