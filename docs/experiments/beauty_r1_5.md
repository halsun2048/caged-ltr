# Beauty R1.5 完整目录稳健性审计

R1.5 不训练新模型，也不重新选择融合参数。它复用 R1.4 的三个 LLMInit
checkpoint，以及仅在 Yelp 验证集锁定的基础语义权重 0.25 和门控残差权重
0.1，对 Beauty 的 50,498 个测试用户和全部 57,289 个物品进行排名。

该阶段属于已经访问 Beauty 测试集之后的 post-hoc 协议审计，不作为新的
一次性外部确认。

## sampled-1000 配对统计

在完整目录评测前，R1.4 的 sampled-1000 逐用户分数经过 5,000 次配对
bootstrap。先对同一用户的三个种子差值求平均，再重采样用户：

- Gate − Fixed Overall NDCG@10：`+0.001249`，
  95% CI `[+0.001065, +0.001437]`。
- Gate − Fixed Tail NDCG@10：`+0.007049`，
  95% CI `[+0.006267, +0.007893]`。
- Real Gate − Shuffled Gate Tail：`+0.017361`，
  95% CI `[+0.015331, +0.019502]`。

四项 sampled-1000 配对验收均通过。

## 完整目录结果

| 方法 | H@10 | NDCG@10 |
|---|---:|---:|
| LLMInit | 0.024192 ± 0.001195 | 0.012107 ± 0.000714 |
| semantic-only | 0.028714 ± 0.000000 | 0.015501 ± 0.000000 |
| 固定融合 | 0.029731 ± 0.000541 | 0.015172 ± 0.000340 |
| 置信门控 | 0.030028 ± 0.000573 | 0.015336 ± 0.000351 |
| shuffled 门控 | 0.022483 ± 0.000899 | 0.011208 ± 0.000512 |

门控相对固定融合的 Overall NDCG@10 三种子增益为
`+0.000213`、`+0.000113`、`+0.000167`；Tail 增益为
`+0.000764`、`+0.000696`、`+0.000472`。方向全部一致，但 Tail 平均绝对
增益只有 `+0.000644`，未达到预设 `0.005` 实际规模阈值。

## 完整目录配对统计

使用保存的逐用户 rank 再执行 5,000 次配对 bootstrap：

- Gate − Fixed Overall：`+0.000164`，
  95% CI `[+0.000109, +0.000222]`。
- Gate − Fixed Tail：`+0.000644`，
  95% CI `[+0.000382, +0.000959]`。
- Real Gate − Shuffled Gate Tail：`+0.000866`，
  95% CI `[+0.000474, +0.001323]`。
- Gate − semantic-only Overall：`-0.000165`，
  95% CI `[-0.001158, +0.000844]`。

因此门控相对固定融合的微小增益具有统计稳定性，但没有预设的实际规模。
门控与 semantic-only 的总体差异不能排除零。

## 结论边界

- 正确物品语义确实有效：真实门控显著超过 shuffled 门控。
- 门控稳定改善固定融合，但 sampled-1000 明显放大了增益规模。
- semantic-only 在完整目录下的 Tail/Cold-start NDCG@10 分别为
  `0.020853`/`0.020727`，门控仅为 `0.001075`/`0.000000`。
- 门控的优势主要来自 Head 与 Torso 的平衡，并未在完整目录下充分释放冻结
  语义支路的长尾能力。
- 后续不得根据 Beauty 测试结果继续调权重；新的机制只能在训练/验证数据上开发，
  并需要新的外部数据或预注册协议确认。
