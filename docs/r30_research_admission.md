# R30 条件化研究准入

项目已停止无边界模型搜索。只有满足以下至少一项才建立新的研究版本：

1. 获得带曝光、点击、停留或转化字段的合规真实日志；
2. 获得未被当前流程使用的新独立排序 benchmark；
3. 获得请求发生前即可计算、且能显著预测 FIRST gain 的新特征；
4. 接入真实 FIRST provider 并取得实际延迟、失败率与费用。

新版本必须重新冻结 train/dev/confirm/test、数据哈希、预算和停止规则。旧 MIND
confirm/large-test 不得重新用于调参。候选方向包括轻量 Pre-Gate、并行推理、
预算约束优化和基于真实行为目标的路由。

在未满足准入条件前，R30 状态为 `not_started_by_design`。
