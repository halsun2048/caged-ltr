## 0. 核心结论

五篇论文组成两段互补链路：

\[
\boxed{
\text{LLM-ESR / RLMRec：表示增强}
\rightarrow
\text{PRP / FIRST：教师偏好}
\rightarrow
\text{Instruction Distillation：轻量学生}
}
\]

最值得研究的空白不是再叠加一个 LLM 模块，而是同时解决：

1. **语义与行为表示的可靠性随曝光量变化**；
2. **LLM 教师偏好有噪声且缺乏置信度校准**；
3. **文本相关性、CTR/CVR、Bid 和风险目标并不等价**；
4. **历史曝光和位置偏差会污染学生监督**；
5. **排序增益必须与 pCTR 校准、延迟和长尾分桶共同验证**。

推荐论文主线：

> **频次与不确定性感知的语义—行为门控，辅以置信度加权的 Pairwise/Listwise 多目标蒸馏。**

避免同时完整堆叠五篇模型。合理设计是：**一个核心创新 + 一个辅助机制 + 一个可信实验闭环。**

## 2. 核心公式对比

### 2.1 表示增强

LLM-ESR 固定拼接：

\[
s(u,i)=
(\mathbf e_i^{sem})^\top\mathbf u^{sem}
+(\mathbf e_i^{collab})^\top\mathbf u^{collab}.
\]

RLMRec 对比对齐：

\[
\mathcal L_{InfoNCE}
=-\sum_i\log
\frac{\exp(\operatorname{sim}(\mathbf e_i^{sem},\mathbf e_i^{collab})/\tau)}
{\sum_j\exp(\operatorname{sim}(\mathbf e_i^{sem},\mathbf e_j^{collab})/\tau)}.
\]

[推导] 二者分别代表“保留双空间后加分”和“把双空间拉近”。它们不是谁一定更优，而是偏置不同：

- 拼接允许差异，但无可靠性权重；
- 强对齐共享信息，但可能抹去有价值的私有因素。

推荐共享—私有分解加门控。

### 2.2 Pairwise 教师与学生

PRP 教师：

\[
(q,a_i,a_j)\rightarrow y_{ij}^{T}.
\]

Instruction Distillation 学生：

\[
\mathcal L_{pair}
=\sum_{i,j}c_{ij}\log(1+e^{-y_{ij}^{T}(s_i-s_j)}).
\]

PRP 原文不提供 \(c_{ij}\)，这是本项目应补充的核心变量。

### 2.3 Listwise 教师

FIRST 的首位置 logits 可规范化为候选分布。下式是面向本项目的[建议]，不是 FIRST 已验证的轻量学生蒸馏方案：

\[
P_T(i\mid q,C)=\operatorname{softmax}(s_i^T/\tau).
\]

学生列表蒸馏：

\[
\mathcal L_{listKD}
=c(C)\tau^2 KL(P_T\parallel P_S).
\]

Pairwise 约束局部困难广告对，Listwise 保留候选集内相对分布；二者在理论上不等价，实验上应检验互补性。

## 4. 文献冲突与统一解释

### 4.1 语言表示能否替代协同表示

| 支持/反对 | 证据 |
|---|---|
| 支持语义有价值 | LLM-ESR 的尾部物品收益主要依赖语义视图；RLMRec 至少一种变体在多数骨干/指标上增强骨干 |
| 反对直接替代 | RLMRec 的 semantic-only 远弱于协同模型；LLM-ESR 去除协同视图总体下降显著 |

结论：[推导] **语义可视为相对高偏差、低方差的先验；行为在长尾处方差更高，但并不天然低偏差，因为曝光策略也会污染行为。应按样本量、来源质量与不确定性融合。**

### 4.2 Pairwise 是否优于 Listwise

| 方法 | 优势 | 缺陷 |
|---|---|---|
| PRP Pairwise | 局部判断简单、输入顺序更稳、适合困难对 | 调用量大、非传递、无全局分布 |
| FIRST Listwise | 一次上下文建模候选集合、可输出软分布 | 7B 成本、ID token/位置偏差、窗口边界 |

结论：不应只选其一。Pairwise 用于高价值边界样本，Listwise 用于 Top-K 整体结构。

### 4.3 更大教师是否必然更好

Instruction Distillation 显示学生吸收能力随容量变化；PRP 显示开放 20B 可在部分数据集接近 GPT-4，但不是全局超过。教师规模不是唯一变量，提示、领域匹配、标签置信度和学生容量共同决定结果。

### 4.4 蒸馏是否改善校准

五篇均没有充分证明蒸馏改善 pCTR 或概率校准。排序 NDCG 提升可能伴随概率失准。广告系统必须独立报告 ECE、Brier Score 和分桶校准。

### 4.5 初始顺序是否影响列表生成

PRP 明确显示 RankGPT 对逆序候选极敏感；PRP-Allpair 最稳，Sliding-K 仍有影响。FIRST 没有做逆序、随机 permutation 或 identifier remapping 实验；图 2 只测首 token 排序与同一模型完整生成排序的一致性，不测真实相关性或概率校准。因此首 token 减少生成误差不等于消除输入位置、标识符或窗口边界偏差。

## 5. 研究空白

### 空白 1：可靠性随曝光量变化未被统一建模

- LLM-ESR 固定双视图加分；
- RLMRec 固定对齐强度；
- 均未把曝光量、广告年龄、文本质量和语义不确定性纳入融合。

可检验假设：

> 尾部广告的最优语义权重高于头部广告，且该权重随行为样本量单调下降。

### 空白 2：教师置信度缺失

- PRP 以一致/不一致形成硬偏好；
- Instruction Distillation 使用硬教师排序；
- FIRST 有 logits 却未以校准置信度蒸馏轻量学生。

可检验假设：

> 置信度加权伪标签比等权硬标签在长尾样本和分布外 Query 上更稳健。

### 空白 3：商业多目标与语言相关性分离不足

现有排序论文主要优化文本相关性。广告系统还需要：

\[
Utility=
\alpha Rel+\beta pCTR+\gamma pCVR\cdot Bid-
\delta Risk.
\]

应把 LLM 相关性教师和行为/商业教师拆分，再进行可解释融合。

### 空白 4：曝光与位置偏差

五篇均未解决广告日志中的 missing-not-at-random。无点击不代表不相关，未曝光更不应视为负例。需要 IPS/SNIPS/DR 或随机流量校正。

### 空白 5：排序、校准与效率缺少统一闭环

可发表的工业论文必须同时证明：

- NDCG/AUC/GAUC 上升；
- Tail Query/Ad 分桶上升；
- ECE/Brier 不恶化；
- 延迟/QPS/参数量可接受；
- 教师离线成本受控。

## 6. 推荐项目方案

### 6.1 研究问题

> 如何根据语义与行为信号的样本依赖可靠性，动态增强长尾 Query/广告表示，并将带噪 LLM Pairwise/Listwise 偏好安全蒸馏到可校准的轻量广告排序模型？

### 6.2 模型名称

**CAGED：Confidence-Aware Gated Semantic–Collaborative Enhancement and Distillation**  
中文：**置信度感知门控语义—协同增强与蒸馏模型**。

### 6.3 三个以内核心创新

1. **频次与不确定性感知门控**：动态融合语义与行为表示；
2. **置信度加权双层蒸馏**：PRP 困难 pair + FIRST list distribution；
3. **偏差校正与校准约束**：IPS 点击损失 + ECE/Brier 相关校准。

### 6.4 模型结构

\[
\mathbf h_i=
 g_i\mathbf e_i^{beh}+(1-g_i)\mathbf e_i^{sem},
\]

\[
g_i=\sigma(MLP[
\log(1+n_i),
\text{age}_i,
\text{textQuality}_i,
\text{semanticEntropy}_i]).
\]

学生综合分数：

\[
s_i^S=f_\theta(q,u,a_i,\mathbf h_i).
\]

教师：

\[
s_i^T=\alpha s_i^{LLM-rel}
+\beta \widehat{pCTR}_i
+\gamma \widehat{pCVR}_i Bid_i
-\delta Risk_i.
\]

### 6.5 联合损失

\[
\mathcal L=
\mathcal L_{click}^{IPS}
+\lambda_a\mathcal L_{align}
+\lambda_p\mathcal L_{pairKD}
+\lambda_l\mathcal L_{listKD}
+\lambda_c\mathcal L_{cal}.
\]

Pairwise：

\[
\mathcal L_{pairKD}=
\sum_{i,j}c_{ij}
\log(1+e^{-y_{ij}(s_i^S-s_j^S)}).
\]

Listwise：

\[
\mathcal L_{listKD}=c(C)\tau^2 KL(P_T^\tau\|P_S^\tau).
\]

### 6.6 理论分析范围

不建议追求大而全的收敛证明。优先证明/分析：

1. 两个无偏噪声表示融合的 MMSE 最优权重；
2. 当协同方差随曝光量下降时，最优行为权重单调上升；
3. 置信度加权对噪声教师梯度贡献的上界；
4. IPS 损失在 propensity 正确时的无偏性条件。

### 6.7 数据与基线

| 模块 | 建议 |
|---|---|
| 公开数据 | 先用 Amazon/Yelp/广告相关公开点击数据；无广告数据时构造 Query-Item proxy |
| 表示基线 | ID-only、LLMInit、RLMRec-Con、LLM-ESR 简化版 |
| 教师基线 | PRP、FIRST hard rank、FIRST soft logits |
| 蒸馏基线 | Instruction Distillation、等权 pair、等权 list |
| 偏差基线 | naive BCE、IPS、SNIPS/DR 可选 |

### 6.8 指标

- 排序：AUC、GAUC、NDCG@K、MRR；
- 长尾：Head/Torso/Tail Query 和 Ad；
- 校准：ECE、Brier Score、Reliability Diagram；
- 教师：pair accuracy、一致率、循环率、entropy；
- 效率：参数量、P50/P95 latency、QPS、教师 token 成本；
- 商业：预期收益、CVR/GMV proxy、风险违规率。

### 6.9 必要消融

1. 无门控/固定门控/频次门控/不确定性门控；
2. Pair-only/List-only/Pair+List；
3. 硬标签/软标签/置信度加权；
4. 无偏差校正/IPS；
5. 无校准损失/有校准损失；
6. LLM-only/行为-only/混合教师；
7. 不同文本质量与曝光量分桶。

### 6.10 最小可行版本

```text
语义：冻结小型文本 encoder，离线生成 Query/Ad embedding
学生：轻量 Cross-Encoder 或 DCN-v2/DeepFM
门控：曝光量 + 广告年龄 + 文本完整度
教师：PRP 只标注困难 pair；FIRST 暂不训练，仅用现成/云端模型生成 logits
损失：BCE + confidence-weighted RankNet + calibration
评测：NDCG/AUC + Tail bucket + ECE + latency
```

这个版本已足以形成清晰论文，不必一开始加入图增强、相似用户检索和完整多目标竞价模块。

## 7. 复现顺序

| 阶段 | 工作 | 目的 |
|---:|---|---|
| 1 | LLM-ESR 简化双视图、RLMRec-Con | 建立语义—行为基线 |
| 2 | PRP 小规模困难 pair | 验证教师偏好质量 |
| 3 | Instruction Distillation | 建立 Pointwise 学生基线 |
| 4 | FIRST logits 蒸馏 | 加入 Listwise 软监督 |
| 5 | 门控、置信度、IPS、校准 | 形成论文创新闭环 |

## 8. 最终决策

| 问题 | 决策 |
|---|---|
| 表示主基线 | LLM-ESR + RLMRec-Con |
| Pairwise 教师主基线 | PRP |
| 蒸馏主基线 | Instruction Distillation |
| Listwise 教师主基线 | FIRST |
| 核心创新 | 频次/不确定性门控 + 置信度加权蒸馏 |
| 理论比例 | 约 20%—25% |
| 实验比例 | 约 75%—80% |
| 最大风险 | 数据缺少真实曝光/位置/Bid/CVR 字段 |
| 避免事项 | 五篇全部堆进一个巨大模型 |

> 最合理的论文不是“把五篇拼起来”，而是以 LLM-ESR/RLMRec 暴露的固定融合缺陷为核心问题，用 PRP/FIRST 提供有置信度的排序监督，再以 Instruction Distillation 完成低延迟学生部署。
