# 终版深度精读说明

本目录依据用户给定的 15 节单篇模板与 6 节多篇综合模板重做，保留四套旧评价作为审计轨迹，不覆盖原文件。

## 文件

- `00_多篇论文综合分析.md`：方法矩阵、公式对比、证据排名、文献冲突、研究空白与项目方案。
- `01_LLM-ESR_终版精读.md`
- `02_RLMRec_终版精读.md`
- `03_PRP_终版精读.md`
- `04_Instruction_Distillation_终版精读.md`
- `05_FIRST_终版精读.md`

## 证据规则

1. `[论文事实]` 只接受论文 Markdown 明确给出的内容。
2. `[推导]` 是机制、统计或理论解释，不冒充作者结论。
3. `[建议]` 是面向长尾搜索广告的迁移设计，不冒充论文贡献。
4. MinerU Markdown 未保留可靠页码，因此采用“节、公式、表、图”定位；无法确认时直接说明材料不足。
5. 对公式符号方向疑似由 OCR/转换造成的问题，只标为“需核对原 PDF/代码”，不宣称作者算法错误。

## 本版重点纠偏

- LLM-ESR 长尾增益统一相对同列最优基线计算，并保留删除协同视图/自蒸馏后尾部指标反升这一负面结果。
- RLMRec 的互信息定理不解释为因果去噪或曝光去偏。
- PRP 的双顺序查询只处理提示内输入次序敏感性，不等于广告日志的位置/曝光偏差校正。
- Instruction Distillation 是无人工相关性标签的伪标签适配，不是“学生无需训练”。
- FIRST 的轻量学生软蒸馏属于本项目建议，不是原论文已经验证的贡献。
