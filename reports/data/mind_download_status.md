# MIND-small acquisition status

The official Microsoft blob endpoints for `MINDsmall_train.zip` and
`MINDsmall_dev.zip` were retried on 2026-08-01 with resume support.  Both
returned HTTP 409 before transferring data.  No MIND files were accepted as
valid, and no substitute mirror was used.

MIND remains a planned independent text/behavior benchmark.  The current
independent benchmark evidence uses the official NFCorpus train split instead.
